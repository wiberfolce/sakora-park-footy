# Sakora Park

Web-based 3D community football game. React + Three.js (react-three-fiber) + Zustand + Vite.

## Run
Uses **npm** only (no Bun anywhere in this project).

    npm install
    npm run dev

Controls: WASD/arrows to move, Space to shoot, E to buy sobolo (speed boost).

## What's in this first slice
Town pick, jersey designer, photo-on-face avatar, 4v4 match vs AI, sandy pitch upgrades, sponsors, vendor boost, crowd and billboards.

## Next
Real photo-to-3D avatars, scheduled/async matches and live multiplayer, more towns, vendor and brand-deal economy, MoMo payments.
